## このソフトについて

TMS（Task_Management_System）は、ブラウザだけで動作するガントチャート形式のタスク管理ツールです。サーバーやインストール作業を必要とせず、HTML・CSS・JavaScriptの3ファイルのみで完結する、いわゆる「静的Webアプリ」として作られています。

## 開発経緯

既存のガントチャートツール（GanttProject等）を使っていく中で、「1つのタスクの作業が一定期間続くのではなく、途中で作業が止まり、しばらくしてから再開される」というケースをうまく表現できないという課題に突き当たりました。多くのツールでは1つのタスクに対して1本の連続した期間バーしか持てないため、作業に空白期間（未作業日）が挟まると、次のような不自然な対応を迫られます。

- 空白期間の前後で別々の新しいタスクとして分割して登録する（本来は1つの作業なのに管理上バラバラになってしまう）
- 元のタスクの期間を空白期間ごと覆うように引き延ばす（実際には作業していない日まで稼働期間として扱われてしまい、進捗や工数の実態と食い違う）

既存のガントチャートツールの中には、1つのタスクの作業が途中で中断し、しばらくしてから再開されるケースを表現する機能（タスクの分割表示）を持つものもありますが、多くは有償版やPRO版限定の機能であったり、無料で使えるツールには未対応のケースも見られます。本ソフトウェアでは、この「作業の中断・再開」を無料かつブラウザだけで完結する形で扱えるようにすることを目的の一つとして開発しました。

TMSでは、この課題に対応するため、1つのサブタスク・ディテールタスクの中に**計画期間・実績期間それぞれ複数の区間を登録できる**設計にしています。区間と区間の間に空白（未作業日）を挟むことができ、ガントチャート上では同じ1行の中に複数のバーとして表示されるため、作業が中断・再開されるようなタスクも、タスクを分割することなく1つのタスクとして無理なく表現できます。

## 主な特徴・メリット

- **計画と実績を分離した複数期間管理**：サブタスク・ディテールタスクはそれぞれ「計画期間」と「実績期間」を別々に、かつ複数区間で登録できます。実績期間が未記入のままステータスを「完了」にすると、計画期間がそのまま実績としてコピーされます。
- **5階層のシンプルな構造**：フォルダー（入れ子可能な整理用の入れ物）／メインタスク（全体行とマイルストーンを持つ管理単位）／サブタスク／ディテールタスク／マイルストーンという構成で、案件の規模に応じて必要な階層だけを使えます。
- **クローズによる一括完了**：フォルダーやメインタスクを「クローズ」にすると、配下のすべてのタスクが連動して完了状態になります（再オープンは自動では連動しないため、意図しない巻き戻りが起きません）。
- **ドラッグ&ドロップでの並び替え・移動**：ガントチャート上でタスクの行を直接ドラッグして、別のフォルダー・メインタスク・サブタスクへの移動や、同じ階層内での順番の入れ替えができます。
- **業務余力の可視化**：日ごとのタスク稼働量を「タスク数ベース」または「工数ベース」で積み上げ棒グラフとして表示し、設定した閾値を超えた日をひと目で確認できます。
- **複数人・複数タブでの同時アクセス制御**：同じタスク管理ファイルを複数のタブ・端末から開いた場合、最初に接続した側のみが編集可能となり、他は自動的に読み取り専用になります。編集中のタブが一定時間操作されない場合は自動的に編集権限が解放され、他のタブがそれを検知すると通知の上で編集可能へ切り替わります（詳細は下記「複数人・複数タブでの同時利用について」を参照）。
- **キーボード操作対応**：Escapeキーでドラッグ操作のキャンセルやモーダルのクローズなど、共通の操作性を確保しています。

## Webアプリであることのメリット（ソフト導入不要）

TMSはブラウザ上で完結する静的なHTML/CSS/JavaScriptのみで構成されており、専用ソフトのインストールやサーバーの用意を必要としません。ファイル操作機能も外部通信を一切行わない設計になっており、接続したタスク管理ファイル（CSV）やブラウザのlocalStorageへの保存のみで完結します。そのため、社内ポリシーでソフトのインストールが制限されているような、セキュリティ管理の厳しい環境であっても、ブラウザが使えるPCさえあればそのまま利用を開始できます。

## 動作環境

- Google Chrome、Microsoft Edgeなど、Chromiumベースのブラウザを推奨します（タスク管理ファイルへの直接接続・自動保存機能である File System Access API を使用しているためです）。
- 上記APIに対応していないブラウザでも、「タスク管理ファイルをダウンロード（手動保存）」および「タスク管理ファイルを読み込む」機能を使うことで、CSVファイルの手動エクスポート・インポートによる利用が可能です。

## 導入方法（手動導入）

1. 本リポジトリから以下の3ファイルをダウンロードします。
   - `Task_Management_System.html`
   - `Task_Management_System.css`
   - `Task_Management_System.js`
2. 上記3ファイルを**すべて同じフォルダー内**に配置してください。HTMLファイルはCSS・JSファイルを相対パスで読み込んでいるため、別々のフォルダーに置くと正しく動作しません。
3. `Task_Management_System.html` をブラウザで開けば起動します。特別なセットアップやビルド作業は不要です。

### ファイルのエンコードについて

3ファイルを編集・保存する場合は、可能であれば**UTF-8N（BOMなしUTF-8）**での保存を推奨します。環境によってUTF-8Nでの保存が難しい場合は、**UTF-8（BOM付き）**でも動作します。

### CSVファイルを用意する場合

タスクデータの読み込み・書き出しにはCSV形式を使用します。CSVを新規に用意する場合は、次のいずれかの方法で作成してください。

- HTMLを起動した状態で「ファイル操作」モーダルを開き、「タスク管理ファイルをダウンロード（手動保存）」からテンプレートとなるCSVを取得する方法
- 既存のCSVと同じ列見出し（ラベル）構成を守った上で、手動でCSVファイルを作成する方法

手動でCSVを作成する場合、列見出しは自動生成されるCSVと**完全に同じラベル・並び順**にする必要があります。見出しが一致しないと正しく読み込まれませんので、迷った場合は一度「ダウンロード（手動保存）」で出力したCSVを雛形として編集することを推奨します。

> **補足**：現行バージョンでは、複数タブでの同時アクセス制御に用いるロック情報を、CSVファイルの最上段（ヘッダー行よりさらに上）に専用マーカー付きの1行として追加しています。この行が無い旧形式のCSVファイルも問題なく読み込めますが、逆に現行版で保存したCSVを旧バージョン（`archive`フォルダ内のアプリ）で開くと、ロック行を正しく認識できない場合がありますのでご注意ください。

## 複数人・複数タブでの同時利用について

TMSは、同じタスク管理ファイルを複数のタブや複数の端末から同時に開いた場合でも、データの競合や上書き事故を避けるための簡易的な排他制御を備えています。

- **編集権限は最初に接続した1つのタブのみ**：あるタブ・端末がタスク管理ファイルに接続すると、そのタブだけが読み書き可能になり、同じファイルを開いた他のタブ・端末は自動的に**読み取り専用**として開かれます。
- **読み取り専用中でも一部の操作は可能**：読み取り専用のタブでも、「タスク管理ファイルをダウンロード（手動保存）」や、フォルダー・タスクの折りたたみ（表示の開閉）操作は行えます。折りたたみ状態はタブごとのローカルな表示状態として保持され、他タブの更新を取り込む際にも維持されます。
- **読み取り専用タブは自動的に最新状態へ追随**：読み取り専用のタブは10秒ごとに編集権限の状態とファイルの実データを確認し、実質的な変更があった場合のみ画面を再描画します。再描画時にはスクロール位置を保存・復元するため、画面が不必要にガタつくことはありません。
- **編集タブが自動的に解放されるケース**：編集権限を持つタブが10分間操作されなかった場合、「一定時間操作が無かったため接続を解放しました」という通知の上で編集権限が自動的に解放されます。
- **解放後の再接続の挙動**：
  - 他のタブがロックを保持していたために読み取り専用になっていたタブは、そのロックが解放されたことを検知すると、**自動的に読み書き可能へ昇格**し、その旨を通知します。
  - 自分自身の無操作（アイドル）によって編集権限が解放された場合は自動では昇格せず、**次に実際に編集操作を行った時点で初めてロックの再取得を試み**、成功・失敗に応じて結果を通知します。
- **再接続時は必ず最新データを読み込み**：編集権限を新たに取得した際（初回接続・再接続・アイドル後の再取得のいずれの場合も）は、まず必ずファイルを再読み込みしてメモリ上のデータを最新化してから、編集操作の受け付けを開始します。そのため、他のタブで加えられた変更が古いデータで上書きされることはありません。

この仕組みにより、複数人・複数端末で同じタスク管理ファイルを扱う場合でも、データの取り合いや意図しない上書きを防ぎながら利用できます。ただし、ブラウザがバックグラウンドタブの処理を間引く場合など、環境によっては編集権限の切り替わりに多少の遅延が生じる可能性があります。重要な編集を行う際は、他のタブ・端末で同じファイルを開いていないかを一度確認することを推奨します。
